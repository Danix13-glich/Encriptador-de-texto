# Encriptador
Una app en Python capaz de encriptar y desencriptar texto e imágenes con facilidad.

# ¿Cómo funciona?
1. Abres la app.
2. Seleccionas el método que quieres usar.
3. Selecciona si quieres codificar o decodificar.
4. Introduce el texto de entrada.
5. (Solo en casos específicos) pulsa el último botón de abajo del todo para configurar ese método.
5.1. Esta función solo la tienen: César, Máquina Enigma e Imagen (esteganografía).
6. Una vez todo configurado, pulsa el botón de procesar y te devolverá el resultado en la casilla de abajo.
7. Puedes pulsar el botón de Copiar para copiarlo en el portapapeles automáticamente o pulsar el botón Limpiar para empezar de nuevo.
